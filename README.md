# Заруба второго цикла

Командная гонка продаж по предоставленному макету. Каждая из 20 монет — отдельная оплата. После сохранения монету заменяет фотография, имя, фамилия и сумма менеджера. Повторные оплаты одного менеджера складываются в рейтинге.

## Использование

Сайт доступен всем посетителям. Кнопка «ВОЙТИ» открывает вход администратора. Логин — `ADMIN`; пароль хранится только в окружении сервера. После входа выберите свободную монету или нажмите «Добавить оплату». Можно выбрать уже существующего менеджера и повторно использовать его фотографию. Нажатие на заполненную монету позволяет исправить или удалить оплату.

Общая касса, процент плана 3 200 000 ₽ и рейтинг пересчитываются автоматически. У посетителей данные обновляются каждые 10 секунд и при возвращении во вкладку. Фотографии принимаются в JPG, PNG и WebP до 5 МБ.

## Устройство проекта

- `app/dashboard.tsx` — интерфейс: дорожка, показатели, рейтинг, формы.
- `app/globals.css`, `app/fonts.css` — адаптивное оформление и эффекты с поддержкой reduced motion.
- `app/api/` — серверное сохранение, загрузка фотографий и вход администратора.
- `db/schema.ts`, `drizzle/` — схема и миграции общей базы Cloudflare D1.
- `public/assets/` — изображения проекта; фон подготовлен из исходного макета без примерных данных.
- `public/fonts/` — локальные кириллические Manrope и Russo One с лицензиями OFL.
- `tests/` — проверка сумм, повторных оплат и основных сценариев API.

Это полноценный сайт с серверной частью на Vinext/React. Страницы отдаются как HTML, интерфейс дополняется JavaScript. GitHub хранит исходники. Сервер, D1 и R2 размещаются в Sites; GitHub Pages сам по себе не выполняет серверные маршруты и не сохраняет общие данные.

## Локальная разработка

Требуется Node.js 22.13+.

1. `npm ci`
2. Создать игнорируемый файл `.dev.vars` с `ADMIN_PASSWORD` и случайным `SESSION_SECRET` (не менее 32 символов).
3. `npm run build`
4. Применить SQL из `drizzle/` к локальной D1 по порядку:
   `node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_vengeful_wind_dancer.sql`
5. `npm run dev` — открыть адрес, который напечатает сервер.

Локальная база и хранилище отделены от опубликованных данных. Для публикации Sites использует `.openai/hosting.json`, подключает `DB` и `BUCKET` и применяет миграции. Задать `ADMIN_PASSWORD` и `SESSION_SECRET` в защищённых переменных среды перед публикацией. Файлы с секретами не входят в репозиторий.

## Проверки

- `node --test tests/payments.test.mjs`
- `node node_modules/typescript/bin/tsc --noEmit`
- Для API: запустить локальный сайт с пустой тестовой базой, задать `TEST_ADMIN_PASSWORD` в окружении и выполнить `node tests/api-smoke.mjs`. Тест запрещает внешние адреса и очищает созданные тестовые записи.

Сессия администратора хранится в подписанной HttpOnly cookie, изменения проверяют источник запроса. Сервер ограничивает попытки входа, проверяет формат изображения, сумму и версию записи, чтобы одновременные правки не затирали друг друга. Производственные оплаты и фотографии не хранятся в браузере или GitHub.
